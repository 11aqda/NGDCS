## 5. Django / DRF 学习清单

### 课程旧（2020）怎么办

不换课。核心概念没变，代码按 Django 5.2 写。

常见差异：

```text
url()                  → path() / re_path()
MIDDLEWARE_CLASSES     → MIDDLEWARE
ugettext()             → gettext()
request.is_ajax()      → 已删除
NullBooleanField       → BooleanField(null=True)
index_together         → Meta.indexes
STATICFILES_STORAGE    → STORAGES
LogoutView             → 只接受 POST
DEFAULT_AUTO_FIELD     → BigAutoField
```

### DRF 必看

```text
04 RESTful
10–11 DRF 入门
13–19 序列化器
24–26 ModelSerializer
27–31 APIView / GenericAPIView
37–40 ViewSet + Router
44–45 认证权限
48–50 过滤/排序/分页
53 异常（可选）
54–55 接口文档（可选）
```

### 可以跳过

```text
01/02 复习预习
05–09 纯 Django REST（略看）
12/17/20/21/32/36/41/42/43/51/56 小结复习
33 源码追踪
```

### 必须自己敲

- 序列化器、`is_valid`、`validated_data`
- `create()` / `update()`
- `APIView` / `get_queryset` / `get_serializer_class`
- `ViewSet` + `Router`
- 权限类、分页、过滤

只看不敲 = 没学。

### 11.9 8000 被谁占用

不要只看“端口通不通”，要看进程路径：

```powershell
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue |
  Select-Object LocalPort,State,OwningProcess

Get-CimInstance Win32_Process -Filter "ProcessId=<PID>" |
  Select-Object ProcessId,ExecutablePath,CommandLine
```

如果路径是：

```text
D:\djangolianshou\.venv\...
```

说明是练习项目，不是看板，先停掉。

### 11.10 实时指标的路径

看板**优先读 Redis，读不到/过期再回退 CSV 最后一行**：

```python
LIVE_METRICS_KEY = "ngdcs:metrics:live"   # 服务端每秒 HSET，TTL 10s
METRICS_CSV = Path(os.environ.get("NGDCS_METRICS_CSV")
                   or BASE_DIR / "data" / "server_metrics.csv")
```

注意：

- 服务端必须实时写 CSV（默认写，除非 `--no-metrics`）
- 只有加 `--live-metrics` 才写 Redis（**默认关**，实验基线不碰 Redis）
- 超过 5 秒没更新，页面显示“最近数据”，不是“运行中”
- 论文工作区跑服务端时，用 `NGDCS_METRICS_CSV` 把路径指到那个工作区的 `data/`
