## 5. Django / DRF 学习清单

### 课程旧（2020）怎么办

不换课。核心概念没变，代码按 Django 5.2 写。

常见差异：

```text
url()                  → path() / re_path()
MIDDLEWARE_CLASSES     → MIDDLEWARE
ugettext()             → gettext()
request.is_ajax()      → 已删除
NullBooleanField       → BooleanField(null=True)
index_together         → Meta.indexes
STATICFILES_STORAGE    → STORAGES
LogoutView             → 只接受 POST
DEFAULT_AUTO_FIELD     → BigAutoField
```

### DRF 必看

```text
04 RESTful
10–11 DRF 入门
13–19 序列化器
24–26 ModelSerializer
27–31 APIView / GenericAPIView
37–40 ViewSet + Router
44–45 认证权限
48–50 过滤/排序/分页
53 异常（可选）
54–55 接口文档（可选）
```

### 可以跳过

```text
01/02 复习预习
05–09 纯 Django REST（略看）
12/17/20/21/32/36/41/42/43/51/56 小结复习
33 源码追踪
```

### 必须自己敲

- 序列化器、`is_valid`、`validated_data`
- `create()` / `update()`
- `APIView` / `get_queryset` / `get_serializer_class`
- `ViewSet` + `Router`
- 权限类、分页、过滤

只看不敲 = 没学。

### 11.2 端口

```text
9527  TCP 游戏服务端
8000  Django
```

同一时间只能有一个 Django 占 8000：

- 游戏端要登录/排行榜：用 `E:\PythonProject` 的 Django
- 要看板：用 `E:\NGDCS-web` 的 Django
- 不能两个同时起

**2026-11-10 实际检查：8000 被 `D:\djangolianshou\.venv` 的 Django 占着，9527 空闲。**  
看板启动前先确认 8000 是不是 `NGDCS-web`，不是就先停掉。

### 11.3 启动脚本的坑

`tools/start_dashboard.bat` 现在只检查：

```text
8000 端口是否 LISTENING
```

这不够。如果 8000 是：

- `djangolianshou` 的 Django
- 或 `game-dev` 的 Django

它们没有 `/dashboard/`，脚本会直接打开 404。

正确逻辑：

```text
请求 http://127.0.0.1:8000/dashboard/
- 200：打开
- 404：提示“8000 被其他 Django 占用，先停掉”
- 连不上：启动 NGDCS-web 的 Django
```

在这个脚本修好之前，**不要提交它**。

### 11.9 8000 被谁占用

不要只看“端口通不通”，要看进程路径：

```powershell
Get-NetTCPConnection -LocalPort 8000 -ErrorAction SilentlyContinue |
  Select-Object LocalPort,State,OwningProcess

Get-CimInstance Win32_Process -Filter "ProcessId=<PID>" |
  Select-Object ProcessId,ExecutablePath,CommandLine
```

如果路径是：

```text
D:\djangolianshou\.venv\...
```

说明是练习项目，不是看板，先停掉。

### 11.10 实时指标的 CSV 路径

Web 当前写死：

```python
METRICS_CSV = Path("E:/PythonProject/data/server_metrics.csv")
```

原因：Web 工作区在 `E:\NGDCS-web`，指标由游戏端写到 `E:\PythonProject\data`。

注意：

- 服务端必须实时写 CSV（默认写，除非 `--no-metrics`）
- 超过 5 秒没更新，页面显示“最近数据”，不是“运行中”
- 最终合并 `portfolio` 后，要改成：

```python
METRICS_CSV = BASE_DIR / "data" / "server_metrics.csv"
```
