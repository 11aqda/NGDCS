# legacy_game/ — 旧原型（仅作参考，**不属于现行系统**）

## 这是什么

2026 年 5 月（毕设开始前）写的一个**单文件版飞机大战**原型。
它和现在的毕设系统**没有任何调用关系**，代码风格、目录结构、通信方式都不同。

保留它只为一件事：**说明演进过程**。

## 与现行架构的区别

| 维度 | `legacy_game/`（旧原型） | 现行系统 |
|---|---|---|
| 运行方式 | **单机**，`python plane-game.py` | C/S 架构，服务端 + 客户端 |
| 通信 | **没有通信**，所有逻辑在一个进程里 | **自定义 12 B 二进制协议** + TCP |
| 同步 | 不需要（同进程） | 服务端权威 + **20 Hz 定频广播** + 插值 |
| 碰撞 | `collision.py` 直接判定并生效 | `sim/collision.py`，实验期**只判定不生效**（测量夹具，见 D-025） |
| 结构 | 根目录散放的 `.py` + `.png` | `protocol/` `server/` `client/` `sim/` `bot/` `tools/` `tests/` |
| 测试 | 无 | **271 个单元测试** |

**一句话**：旧原型证明"能把游戏跑起来"，现行系统要回答的是"**这套数据通信在压力下表现如何**"。

## 文件清单

| 文件 | 作用 |
|---|---|
| `plane-game.py` | 入口（单文件主循环） |
| `player.py` | 玩家飞机 |
| `enemy.py` | 敌机 |
| `bullet.py` | 子弹 |
| `control.py` | 键盘控制 |
| `collision.py` | 碰撞检测（此版本**生效**） |
| `http_test.py` | 早期试 HTTP 的小脚本 |
| `hero.png` / `enemy0.png` / `bullet.png` | 素材 |

> 这些文件之间**互相 import**（`plane-game.py` 依赖其余全部），
> 所以必须整组放在同一目录 —— 拆开就会 `ModuleNotFoundError`。

## ⚠️ 注意事项

1. **不要把它接入现行系统**，也不要为了"统一风格"去改它 —— 它的价值就是"保持原样"
2. **不要把它纳入测试**：根目录已无 `.py`，`unittest discover -s tests` 不会扫到它
3. 它是**参考**，不是**依赖**：删掉它现行系统照常运行

## 为什么当初从根目录挪过来

2026-10-29 清理仓库时发现：这些文件散落在**项目根目录**，与 `protocol/`、`server/` 等
正式目录平级，容易被误认为现行代码的一部分。同时根目录还混进了一个 **1.9 MB 的 mp3**
和一个**随机 jpg**（均已删除）。

移到子目录后，根目录只剩 `.gitignore`，一眼就能看出项目结构。
